# VIBE-HR Brand Assets

`03 VIBE MONOGRAM`을 VIBE-HR의 기본 마스터 로고로 사용합니다.

## 마스터 컬러

- Cobalt: `#3C6DEE`
- Steel: `#A8B3C5`
- Ink: `#0E1B31`
- White: `#FFFFFF`

## 사용 기준

- 기본 밝은 배경: `vibehr-mark-color.svg`, `vibehr-lockup-color.svg`
- 단색 인쇄·작은 UI: `*-mono.svg`
- 짙은 배경·Navigator Rail: `*-white.svg`
- 짙은 배경의 2색 조합: `vibehr-lockup-dark.svg`
- PNG 파일은 모두 투명 배경이며, 플랫폼 아이콘만 OS 표시 품질을 위해 전용 배경을 포함합니다.

SVG 및 PNG 파생 자산은 `npm run generate:brand-assets`로 재생성합니다. 도형을 개별 파일에서 직접 수정하지 않습니다.
