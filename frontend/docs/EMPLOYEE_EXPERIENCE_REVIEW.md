# 비업무 영역 개선 검증

2026-09-06. 로그인, 상단 바, 계정 메뉴, 사이드바, 모바일 메뉴와 조회 전용 프로필을 개선했다.

**Nielsen 독립 평가 37/40, 시각 평가 94/100.** 최초 잠정 평가는 22/40이었다. 구현 후 32점 평가에서 남은 항목을 추가로 수정하고 최종 37점을 받았다. 최초 평가는 내부 화면의 소스 검토를 포함한 잠정치였으며, 최종 평가는 실제 Chromium 캡처와 동작 검사로 근거를 보강했다.

평가는 서로 독립된 코드 검토와 사용성 검토를 거쳤다. 시각 점수는 브랜드 방향과 구성에 대한 판단이며 픽셀 일치율이나 사용자 만족도 조사 결과가 아니다.

## 검증 근거

- `npm run validate:grid`: 등록된 모든 화면 통과.
- `npm run lint`: 오류 0, 변경하지 않은 업무 모듈의 기존 경고 15개.
- `npm run test`: 19개 파일, 146개 테스트 통과.
- `npx tsc --noEmit`: 통과.
- `node node_modules/@playwright/test/cli.js test --config playwright.experience.config.ts --reporter=list`: 전체 30개 통과, 실패와 건너뜀 0개.
- `npm run build`: 타입 검사와 190개 경로 생성 통과.
- 독립 코드 검토: 최종 승인. 발견한 포커스, 반응형 모달, 요청 취소와 세션 경계를 수정하고 회귀 테스트에 포함했다.

게시 CI에서 기준 main에도 있던 생성 문서 불일치를 확인했다. Spring 스키마 검증 문서의 Java 파일 수만 138에서 140으로 갱신했다. 원본 Git 파일 기준으로 스키마, 변경 기록과 Flyway 검증이 통과했으며 실제 스키마나 마이그레이션을 바꾸지 않았다.

데스크톱, 다크 모드, 390x844 모바일, 390x500의 짧은 화면을 확인했다. 캡처는 글꼴과 데이터 준비, 유한 애니메이션 종료 후 저장했다. 기존 고객사 업무 표와 추가 개발 화면 이동도 검증했다.

주요 회귀는 잘못된 로그인 입력, 서버와 네트워크 오류, 회사 목록 재조회, 프로필 오류와 지연 재시도 취소, 모달 포커스 복귀, 실제 하단 스크롤, 모션 감소, 설정 적용과 취소, 일반 사용자 메뉴, 탭 정리와 활성 본문 동기화, 모바일 메뉴를 연 상태의 창 크기 변경이다.

세션 검증에는 연장 성공 후 시간 조회만 실패하는 경우와 잘못된 남은 시간 응답을 포함했다. 이전 카운터를 새 토큰의 만료 근거로 사용하지 않으며, 서버가 확인한 인증 해제와 유효한 숫자 0의 만료 처리는 유지한다.

## 범위와 한계

실제 Next.js UI와 BFF를 loopback의 합성 백엔드로 검증했다. 기존 Oracle 서비스와 PostgreSQL은 변경하지 않았다. 이 검증은 Spring 인증과 권한 정책, 실서비스 OAuth 연결, 실제 조직의 모든 데이터나 실사용자 연구를 대체하지 않는다.

소셜 안내는 Spring의 이메일 조회와 신규 계정 생성 로직을 직접 확인해 작성했다. 기존 계정 연결이 필수라고 가정하지 않는다. 체험용 기본 입력값은 기존 동작으로 유지했다.

만점 제한은 체험용 입력값과 기본 회사 선택, 추가 숙련자 가속 기능, 실제 지원 채널 정보다. 담당자 연락처나 인증 정책을 임의로 만들거나 변경하지 않았다. 프로필 보조 글자의 대표 색상 쌍은 밝은 모드 약 4.76:1, 어두운 모드 약 6.54:1이며 전체 접근성 적합성 인증은 아니다.

구성과 유지 규칙은 [DESIGN.md](../DESIGN.md), 실행 가능한 동작 검사는 [employee-experience.spec.ts](../tests/e2e/employee-experience.spec.ts)에 있다.
