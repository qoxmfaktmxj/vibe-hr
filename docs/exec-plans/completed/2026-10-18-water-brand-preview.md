# 물결 브랜드 장면 미리보기

- 범위: R1 랜딩의 09 물결 장면, 미리보기 미디어와 확대 화면. 기존 로그인 원본 렌더러와 유체 글자를 재사용한다.
- 연출: 평소에는 잔잔한 물결, VIBE-HR를 지나는 커서에서 글자가 물처럼 흐트러졌다가 돌아온다. 클릭하면 확대하여 직접 제어한다.
- 재생 기준: 현재 보고 있는 장면 하나만 재생한다. 화면 밖, 숨겨진 탭, 사용자 일시 정지, 모션 감소 설정에서는 멈춘다.
- 미리보기 커서: 사용자가 자동 시연 후 클릭 제어 안을 선택했다.

1. 확대 장면에 기존 유체 글자를 연결한다. 검증: 글자 렌더링, 커서 반응, 정지/재생, 닫기 후 해제.
2. 3D 액자와 목록에 미리보기를 연결한다. 검증: 09 선택에서 재생, 다른 장면과 동시 재생 없음, 확대 시 제어 인계.
3. 실제 렌더링과 모바일/모션 감소를 검증한다. 기존 랜딩 및 물결 회귀, 최종 check:ui, 로컬 미리보기와 작업 기록을 갱신한다.

기존 의존성을 유지한다. 내부 업무 화면, 인증, API, 원본 로그인 소스는 변경하지 않는다. 로컬 미리보기 검증 후 사용자가 해당 변경의 푸시를 요청했다.

완료: 약12초 H.264 시연을 제작하고 3D/목록과 확대 제어를 연결했다. 모션11, 랜딩17, 원본GPU1, 기존UI2의 브라우저31개와 unit312, lint, build/TypeScript/grid 검사가 통과했다. 새 production build의 데스크톱과 모바일도 확인했다. 원본 로그인 소스와 포스터7개는 HEAD와 일치한다. 상세 기록은 docs/design/2026-10-18-water-brand-preview.md와 docs/TASK_LEDGER.md에 있다.
