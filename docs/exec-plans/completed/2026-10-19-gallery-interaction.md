# 갤러리 커서와 이동 감각

- 범위: R1 공개 랜딩의 커서, 포커스 표시, 스크롤과 드래그. 기존17장면, 확대, 단독 재생과 물결을 유지한다.
- 근거: alimdesigner.com의 실제 데스크톱 동작과 REA에서 읽은 공개 페이지 스크립트를 비교했다. 회전 목표를 감쇠하여 따라가는 카메라와 장면 전환 중 작은 후퇴가 확인됐다. 사이트의 코드, 미디어와 이름표를 복제하지 않는다.
- 파란 띠: canvas 전체 포커스 테두리를 제거하고 키보드 포커스는 조작 안내에 작은 표시로 남긴다.
- 커서: 이름표 없는 코발트색 SVG 화살표를 사용한다. 기본/드래그 모두 손 모양으로 바뀌지 않는다.
- 움직임: 휠 입력을 짧게 누적하고 다음 장면으로 진행한다. 드래그 목표 각도를 감쇠하여 따라가며 손을 놓으면 부드럽게 정착한다. 장면 전환 시 작은 후퇴와 복귀를 더한다.
- 후속 요청: 선택한 제품 화면의 외곽에 얇은 파란 선과 네 모서리 사각 표시를 추가한다. 화면 원근과 카메라 이동에 맞춰 투영하며 클릭과 드래그 입력을 가로막지 않는다. 캔버스 전체 띠는 계속 표시하지 않는다.

1. 커서/포커스/카메라를 좁게 수정한다. 검증: 포인터 클릭에 바깥 띠 없음, 키보드 접근성, 색상 화살표 유지.
2. 입력과 렌더링을 검증한다. 드래그 직후 추가 이동과 정착, 클릭/드래그 구분, 스크롤 반전/경계, 장면 바로가기와 확대가 맞는지 확인한다.
3. 기존 랜딩/모션 회귀와 최종 check:ui를 실행한다. 실제 desktop/mobile 화면과 로컬 production 빌드를 확인한다.

기존 Three.js와 CSS만 사용한다. 새 의존성, 내부 업무 화면, 인증과 배포 설정 변경은 없다. 원격 main의 후속 CI 보정 커밋은 보존한다. 2026-10-21 사용자의 푸시 요청에 따라 해당 커밋을 먼저 fast-forward로 반영한 뒤 갤러리 변경을 게시한다.

완료: 커서/감쇠 단계의 랜딩19개, 모션11개와 공통 check:ui가 통과했다. 후속 선택 테두리 추가 후 랜딩20개와 공통 check:ui를 다시 통과했다. 최종 빌드에서 네 모서리 오차0.01px 미만, 원근 추종, 클릭 확대, 전체 공간 복귀와 모바일 해제를 확인했다. 검증 결과는 docs/design/2026-10-19-gallery-interaction.md 및 frontend/output/gallery-interaction-20261019/outline-verification.json에 있다.
