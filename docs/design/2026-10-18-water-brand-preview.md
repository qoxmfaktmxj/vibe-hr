# 물결과 VIBE-HR 브랜드 미리보기

사용자는 미리보기에서 커서 움직임을 자동 시연하고 클릭 후 직접 제어하는 안을 선택했다. 09 장면에서 기존 물결과 VIBE-HR 유체 글자를 함께 보여준다.

## 표현과 동작

- 약 12초 동안 잔잔한 물결, 글자를 훑는 자동 커서, 글자 복원을 반복한다. 오디오는 없다.
- 3D 공간과 목록에서 현재 보고 있는 장면 하나만 재생한다. 다른 장면으로 이동하면 이전 미디어를 해제한다.
- 확대하면 미리보기 영상을 멈추고 기존 물결 렌더러와 유체 글자를 시작한다. 실제 마우스에 따라 글자와 물결이 반응한다.
- 일시 정지, 숨겨진 탭, 화면 밖에서 재생을 멈춘다. 모션 감소 설정에서는 영상과 물결 렌더러를 요청하지 않는다.
- 확대 화면은 중앙 VIBE-HR 구도를 사용한다. 로그인 원본의 소스, 배치와 배경 이미지는 유지한다.

## 구현과 미디어

기존 `motion-player.ts`가 물결의 MP4도 처리하도록 확장했다. 별도 재생 프레임워크나 의존성은 추가하지 않았다. `water-exhibit.tsx`는 기존 `createLiquidTitle`을 기존 물결 렌더러 위에 합성한다.

미리보기 파일은 `frontend/public/images/product/motion/09/preview.mp4`다. H.264, 1280x800, 30fps이며 1,265,406바이트다. 출처와 SHA-256은 같은 폴더의 `provenance.json`에 기록한다. 실제 내부 업무 화면이나 운영 데이터는 녹화하지 않았다.

재생성은 frontend에서 기존 로컬 ffmpeg가 설치된 환경을 사용한다.

```powershell
$env:VIBEHR_CAPTURE_WATER = '1'
npx playwright test --config playwright.water-preview.config.ts
```

캡처 전 갤러리 초기화를 기다린 다음 09 장면을 선택한다. 첫 실행에서는 초기화 전 선택이 초기 목록 상태로 덮여 다른 장면을 열었다. `data-ready`를 기다리도록 수정한 뒤 캡처에 성공했으며 실패 trace는 로컬 증거 폴더에 보존했다.

## 검증

모션 브라우저 검사 11개가 통과했다. 물결 미리보기 전용 검사는 단독 재생, 정지/복원, 확대 제어 인계, 모바일 목록, 화면 밖과 비활성 탭 정지, 모션 감소 시 영상 미요청을 확인한다. 실제 픽셀 비교로 커서가 글자 윤곽을 바꾸고 이후 복원되는지도 검증한다.

최종 랜딩 회귀, 원본 로그인 GPU 검사와 공통 빌드 결과는 작업 원장과 `frontend/output/landing-20261018/water-preview-verification.json`에 기록한다. 실행 로그, 영상 원본, 장면별 캡처와 원본 보존 확인은 로컬 증거로 유지한다.

이 구현은 로컬 Chromium/D3D11에서 검증한다. 영상 디코딩이나 WebGL을 지원하지 않는 환경에서는 기존 정지 이미지를 유지한다. 자동 시연은 미리 렌더링한 영상이며 실제 커서 제어는 확대 화면에서 이루어진다.
