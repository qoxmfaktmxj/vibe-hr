# Vibe-HR Security Policy

Status: Active

## Security Boundary

The Next.js BFF forwards requests to the Rust API. Its authentication middleware validates bearer tokens, active account status and signed BFF requests. Backend domain handlers enforce role, ownership, menu and action permissions. New social accounts receive independent random local credentials.

## Protected Data

Employee identity, organization records, time records, payroll, severance, welfare, credentials, tokens, and migration metadata are sensitive. Do not log raw values, place them in fixtures, or copy them into task evidence.

## Runtime Rules

- Supply datasource credentials plus distinct `AUTH_TOKEN_SECRET` and `VIBEHR_BFF_ASSERTION_SECRET` values through environment variables. Each secret must be exactly 64 hexadecimal characters generated by `openssl rand -hex 32`.
- Flyway owns schema and required reference data. SQLx validates the application catalog during cutover. The retained Spring comparison uses Hibernate validation.
- Restrict fixture seeding to the explicit local or demo profile gate.
- The public allowlist covers health probes, API documentation, login corporation discovery and active options for a code group. Login and social exchange require a valid signed BFF assertion.
- Use `BigDecimal` and explicit rounding tests for financial behavior.
- The public reverse proxy must remove every client-supplied `X-VibeHR-Client-IP` header and set exactly one canonical IP literal before forwarding to the loopback-only Next.js BFF. `VIBEHR_BFF_TRUSTED_CLIENT_IP_HEADER` is fixed to `x-vibehr-client-ip`; missing, malformed, or multi-value headers fail closed before a BFF assertion is signed. Do not use `X-Forwarded-For` or `Forwarded` for this boundary.

## Required Review

Authentication, authorization, secrets, Flyway, payroll, data repair, and deployment work are R3. They require explicit approval, focused backend tests, PostgreSQL integration coverage where applicable, and documented recovery evidence. Security fixes must include a regression test unless that is infeasible and the reason is recorded.
