## 5. 현재 작업 시 특히 조심할 영역
### A. 로그인/인증
- `ENTER_CD`가 포함된 구조라 일반 로그인으로 오해하면 안 된다.
- dev 계정 정보만 보고 인증을 단순화하면 위험하다.

### B. AG Grid 표준 화면
- 화면 하나를 고쳐도 registry / toolbar / dirty-row / row status / pagination / save order까지 같이 맞아야 한다.

### C. 급여/근태/복리후생
- 샘플 데이터는 풍부하지만, 도메인 규칙은 아직 진행 중인 부분이 있다.
- seed 데이터가 존재한다는 이유만으로 도메인 완성으로 판단하면 안 된다.

### D. 권한
- 메뉴 표시 여부와 액션 권한은 분리되는 방향이다.
- 프론트 노출만 바꾸고 서버를 안 바꾸면 불완전하다.

## 8. 2026-07-08 점검 반영
이번 점검의 현재 결론은 다음과 같이 본다.

- 디자인 개편 방향은 보류한다. 지금은 화면 톤 변경보다 업무 흐름 검증과 AG Grid 표준화가 우선이다.
- 채용 최종합격자 → 사원화 → 발령확정 → 근태/복리후생 → 급여 계산/마감/지급 흐름은 API 기준으로 주요 구간이 동작한다.
- 급여 → 전표/GL 연결 모듈은 현재 부재한다. 이 구간은 라이프사이클의 명확한 단절이며, 설계부터 R3 승인 대상으로 본다.
- 퇴직 케이스 → 체크리스트 → 확정 → 직원 `resigned` 전환은 확인됐지만, 퇴직금 계산/정산과 퇴직 확정 후 조직 정리는 별도 후속이다.
- 개발 DB 더미데이터는 이미 보강됐으나, 추가 seed/backfill은 DB 작업이므로 R3 승인 없이 진행하지 않는다.
- `npm run validate:grid`는 2026-07-08 재실행 기준 통과했다.

## 9. vibe-grid 활용 방안
`vibe-grid`는 디자인 결정 도구가 아니라 **AG Grid 화면의 표준화/검증/마이그레이션 가드**로 사용한다.

### 즉시 적용할 방식
- AG Grid 화면을 건드릴 때마다 `config/grid-screens.json` → `docs/GRID_SCREEN_STANDARD.md` → `docs/AG_GRID_COMMON_GUIDE.md` → 대상 화면 순서로 읽는다.
- `query -> create -> copy -> template -> upload -> save -> download` toolbar 순서를 기준으로 이탈 화면을 분류한다.
- 모든 `AgGridReact` 화면에 `GRID_SCREEN` 메타데이터와 registry 등록이 맞는지 `npm run validate:grid`로 먼저 확인한다.
- 라이프사이클 핵심 화면을 회귀 검증 대표군으로 둔다.
  - 채용: `/hr/recruit/finalists`
  - 인사정보: `/hr/employee`
  - 조직/발령: `/hr/appointment/records`, `/org/departments`
  - 근태: `/tim/status`, `/tim/month-close`
  - 복리후생: `/wel/requests`, `/wel/my-requests`
  - 급여: `/payroll/runs`
  - 퇴직: `/hr/retire/checklist`

### 승인 후 진행할 R2 단위
- `docs/VIBE_GRID_ROADMAP.md`의 `VibeGrid` 래퍼 구현은 공유 grid 컴포넌트와 registry 계약을 바꾸므로 R2로 분리한다.
- 첫 파일럿은 읽기전용 또는 단순 조회 화면 1개로 제한한다.
  - 후보 1: `/hr/retire/checklist`
  - 후보 2: `/org/dept-history`
  - 후보 3: `/tim/reports`
- 파일럿 검증은 `npm run validate:grid` → `npm run lint` → `npm run build` → 브라우저 렌더 확인 순서로 고정한다.

### 아직 하지 않을 것
- 디자인 테마 전면 개편
- 전표/퇴직금/급여 의미 변경
- 운영성 seed/backfill
- `frontend/src/components/grid/**`, `frontend/src/lib/grid/**`, `config/grid-screens.json` 변경 없이 승인된 R2 범위를 넘어가는 작업
